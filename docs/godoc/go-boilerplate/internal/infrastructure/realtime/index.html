Overview ▾

Package realtime は、Realtime Delivery の fan-out substrate（wakeup の publish と、serve instance ごとの 受信先）の実装を選ぶ唯一の場所です。背後の substrate を差し替える場合に書き換えるのはこのパッケージだけで、 DI はここを通ります。
