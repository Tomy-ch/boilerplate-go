Package dynamodb は、EventLog 境界（realtime.EventLogStore）の DynamoDB 実装を提供します。 partition key は stream、sort key は sequence で、1 stream の event が sequence 順に並びます。 期限切れの掃除は TTL に任せますが、replay できるかの判定（保持期間）は usecase 側の時計で行います。
