Package core は、HTTP ミドルウェア層で使用する Fx モジュール群を提供します。 認証（AuthnModule）・リクエストバリデーション（ValidatorModule）・セキュリティ Cookie （SecurityCookieModule）・スキッパー（SkipperModule）・Basic 認証（BasicAuthModule）を含みます。

func RedactionModule ¶ 

func RedactionModule() fx.Option

RedactionModule は、ログへ出す前に資格情報を取り除く Redactor を提供する fx モジュールを返します。 秘匿対象名は OpenAPI spec の securityScheme のうち query の apiKey から導出します。
