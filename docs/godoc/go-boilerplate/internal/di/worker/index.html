func ValidateShutdownGrace ¶ 

func ValidateShutdownGrace(appCfg *config.ApplicationConfig, workerCfg *config.WorkerConfig) error

ValidateShutdownGrace は、drain 完了前に停止猶予が尽きないことを起動時に検証します。

WORKER_DRAIN_TIMEOUT >= APP_SHUTDOWN_TIMEOUT だと OnStop の drain が停止猶予で打ち切られ、 未完了の in-flight handler と後続の停止処理（DB pool close 等）が競合します。 設定不整合は起動時に失敗させ、運用時の競合を未然に防ぎます。
