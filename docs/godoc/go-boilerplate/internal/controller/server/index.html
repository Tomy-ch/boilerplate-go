func NewHTTPServer ¶

NewHTTPServer は、Echo をハンドラとする HTTP サーバーを作成します。 Echo v5 の echo.StartConfig を使わない理由は ADR-0022 (echo-http-framework) を参照。

func ResponseOf ¶ 

func ResponseOf(c *echo.Context) *echo.Response

ResponseOf は、Echo コンテキストから echo.Response を取り出します。 Echo v5 の Context.Response() は http.ResponseWriter を返すため、 ステータスや Before/After フックを扱うにはこの unwrap が要ります。 レスポンスライタが Echo のレスポンスへ辿れない場合は nil を返します。
