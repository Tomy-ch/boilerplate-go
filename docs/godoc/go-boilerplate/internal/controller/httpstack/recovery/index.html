Middleware は、Echoフレームワークのミドルウェアで、パニックからのリカバリを行います。

middleware.RecoverWithConfig は復帰した panic を middleware.PanicStackError へ包んで 戻り値のエラーとして返すため、その外側でスタック付きのログを出し、 エラーハンドラへは包む前のエラーを渡します。
