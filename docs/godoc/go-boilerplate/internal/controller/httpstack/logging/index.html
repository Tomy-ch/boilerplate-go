func Middleware ¶ 

func Middleware(logger logging.Logger, lf logging.LogFieldBuilder, red redaction.Redactor) echo.MiddlewareFunc

Middleware は、Echoフレームワークのミドルウェアで、リクエストのログを出力します。 ただし /health, /metrics 等の運用系エンドポイントはログ出力をスキップし、SSE として確定した接続は 応答ログだけをスキップします（その 1 行は接続が閉じるまで出ず、duration もリクエストではなく接続の 長さになるため）。確定前の拒否は普通のレスポンスなので、要求ログも応答ログもそのまま出ます。 レスポンスを取り出せない場合はログを出さず素通しします。 URI と query は red を通してから出すため、query で運ばれる資格情報はログに残りません。
