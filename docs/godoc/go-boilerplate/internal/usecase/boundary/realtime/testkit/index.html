type EventLog ¶

EventLog は、in-memory の rt.EventLogStore です。読み取りは常に最新の書き込みを反映します （実装は強い一貫性の読み取りとして振る舞います）。

正規の Append では作れない状態を組み立てる専用の口（Seed / SetUnavailable / Hold / SeedAppendedThrough）を持ちます。 各口の使い分けは README を参照してください。 

type EventLog struct {
    // contains filtered or unexported fields
}

func NewEventLog ¶ 

func NewEventLog() *EventLog

NewEventLog は、空の EventLog を生成します。

func (*EventLog) Append ¶ 

func (l *EventLog) Append(_ context.Context, event rt.DeliveryEvent) error

Append は、event を (StreamID, Sequence) へ 1 度だけ書きます。同じ位置に同じ EventID があれば成功、 異なる EventID があれば rt.ErrSequenceConflict を返します。

func (*EventLog) AppendedThrough ¶ 

func (l *EventLog) AppendedThrough(_ context.Context, streamID rt.StreamID) (rt.Sequence, error)

AppendedThrough は、Append で書いた最大の位置を返します。Seed は正規の追記ではないので数えません。

func (*EventLog) Find ¶ 

func (l *EventLog) Find(_ context.Context, streamID rt.StreamID, seq rt.Sequence) (rt.DeliveryEvent, bool, error)

Find は、stream の slice を走査して sequence の一致する event を返します。無ければ ok=false です。

func (*EventLog) Hold ¶ 

func (l *EventLog) Hold() func()

Hold は、以降の読み取りを、返った関数が呼ばれるまで待たせます （EventLog の doc にある専用の口の一つ）。

func (*EventLog) Latest ¶ 

func (l *EventLog) Latest(_ context.Context, streamID rt.StreamID) (rt.DeliveryEvent, bool, error)

Latest は、sequence 昇順に保った slice の末尾を返します。stream が空なら ok=false です。

func (*EventLog) ReadAfter ¶ 

func (l *EventLog) ReadAfter(ctx context.Context, q rt.ReadAfterQuery) (rt.ReadAfterResult, error)

ReadAfter は、q.After より後ろの event を sequence 昇順に最大 q.Limit 件返します。

func (*EventLog) Seed ¶ 

func (l *EventLog) Seed(events ...rt.DeliveryEvent)

Seed は、Validate も冪等判定も通さずに event を置きます。飛び番や保持期間外の位置を作れます （EventLog の doc にある専用の口の一つ）。

func (*EventLog) SeedAppendedThrough ¶ 

func (l *EventLog) SeedAppendedThrough(streamID rt.StreamID, seq rt.Sequence)

SeedAppendedThrough は、Append を経ずに追記済みの位置を置きます。保持期間で event が消えたあとの 状態を作れます（EventLog の doc にある専用の口の一つ）。

func (*EventLog) SetUnavailable ¶ 

func (l *EventLog) SetUnavailable(v bool)

SetUnavailable は、以降の読み書きが apperror.ErrUnavailable を返すかどうかを切り替えます。

func (s *StreamTicketStore) Find(_ context.Context, hash rt.TicketHash, asOf time.Time) (rt.StreamTicket, bool, error)

Invalidate は、subject × destination に発行された ticket をすべて落とします。該当が無くてもエラーになりません。
