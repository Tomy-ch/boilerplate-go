type FS ¶

FS は、ファイルシステム操作を抽象化するインターフェースです。 

type FS interface {
    ReadFile(name string) ([]byte, error)
    WriteFile(name string, data []byte, perm os.FileMode) error
    Glob(pattern string) ([]string, error)
    MkdirAll(path string, perm os.FileMode) error
}

type OS ¶

OS は、os / path/filepath を用いた FS の実装です。 

type OS struct{}

func (OS) Glob ¶ 

func (OS) Glob(pattern string) ([]string, error)

Glob は、pattern に一致するファイルパスの一覧を返します。

func (OS) MkdirAll ¶ 

func (OS) MkdirAll(path string, perm os.FileMode) error

MkdirAll は、path のディレクトリを親ごと作成します。既に存在する場合は何もしません。

func (OS) ReadFile ¶ 

func (OS) ReadFile(name string) ([]byte, error)

ReadFile は、name のファイル内容全体を読み込んで返します。

func (OS) WriteFile ¶ 

func (OS) WriteFile(name string, data []byte, perm os.FileMode) error

WriteFile は、data を name のファイルへ書き込みます。ファイルが存在しない場合は perm で新規作成し、 既に存在する場合はパーミッションを変えずに既存内容を切り詰めてから書き込みます。
