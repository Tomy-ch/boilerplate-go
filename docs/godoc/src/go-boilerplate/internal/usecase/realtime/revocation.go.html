    12  // AccessRevoker は、feature が subject の destination への権利を取り下げたときに呼ぶ失効の seam です。
    13  // この service の中で起きた失効は即時に伝わり（ADR-0074）、IdP 側の失効はここを通りません。
    14  type AccessRevoker interface {
    15  	// Revoke は、subject へ destination に対して発行済みの ticket をすべて無効にしたうえで、
    16  	// 開いている接続を閉じるよう各 instance へ伝えます。該当する ticket や接続が無くてもエラーになりません。
    17  	// 無効化が先で、通知に失敗しても無効化は成立しています（順序の根拠は README / ADR-0074）。
    18  	Revoke(ctx context.Context, subject string, destination rt.StreamID) error
    19  }
